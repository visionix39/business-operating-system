# Portico — Property Rental Platform

Frontend portfolio demo of an Airbnb-style property rental product. Built with React, TypeScript, and Vite.

## Features

- **Maps** — interactive Leaflet map with priced pins
- **Property listings** — browse, filter, and search curated stays
- **Booking** — date selection, pricing summary, request-to-book flow
- **Calendar** — availability calendar with booked nights blocked
- **Reviews** — ratings list + leave-a-review form
- **Image upload** — drag-and-drop photo upload for hosts
- **Chat** — guest ↔ host messaging with simulated replies
- **Admin dashboard** — listings, bookings, reviews, and message overview

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Stack

React 19 · TypeScript · React Router · Leaflet · date-fns · Lucide icons

All data is mocked client-side for portfolio presentation — no backend required.
